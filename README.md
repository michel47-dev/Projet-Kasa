# Kasa - Projet React OpenClassrooms

## Description
Projet réalisé dans le cadre de la formation OpenClassrooms Intégrateur Web.

Kasa est une application de location immobilière développée avec React.

Le projet utilise :
- React
- React Router
- SCSS
- Responsive Design

---

## Fonctionnalités
- Affichage dynamique des logements
- Navigation entre les pages avec React Router
- Page détail des logements
- Carrousel d’images
- Collapse animé
- Gestion des erreurs 404
- Responsive mobile et desktop

---

## Technologies utilisées
- React
- React Router
- SCSS
- JavaScript
- Vite
